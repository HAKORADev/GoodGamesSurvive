the four console shelves of the catalogue - one collection per machine, one emulator law for all.

ABOUT THIS MULTI-COLLECTION

The console digs live in per-machine collections - playstation, playstation 2, playstation portable and wii - each page played on windows through its official emulator: duckstation, pcsx2, ppsspp and dolphin. The multi-collection below is the door to all four.

The one-platform law: each game digs as one platform - native windows when a windows build exists, the one supported console when it does not. ps3, ps4, xbox, wii u, switch and anything phone-shaped stay outside the vaults.
