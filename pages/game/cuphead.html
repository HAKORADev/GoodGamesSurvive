ABOUT CUPHEAD

Cuphead is a run-and-gun built inside 1930s cartoon aesthetics: every sprite ink-drawn on paper, every boss a fleischer-era set piece with three phases, every fight judged by parries, supers and no-hit pride. The run-and-gun stages alternate with the boss gauntlet, and the shop's charms and weapons are the only mercy the game extends.

Studio mdhr shipped it in september 2017, first on xbox and windows together, and the steam listing is the current official door at full price. The windows build is the original platform - not a port of a console exclusive.

It is a 2d hand-drawn game of modest engine weight - the haswell igpu bar holds it at 1080p comfortably. The status box stays honest: not-tested until a run confirms the install and the save structure.
