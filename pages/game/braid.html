ABOUT BRAID

Braid is the puzzle-platformer that helped start the indie wave: tim runs left through a story about a princess, and each world rewrites time's rules - simple rewind, objects immune to it, time tied to horizontal position, slowed bubbles, and a finale where the rewind itself is the plot twist. The puzzles are hand-laid and unsolvable by reflex; every piece exists to be understood.

Jonathan blow shipped it on xbox live arcade in 2008 and number none brought the windows build to steam in april 2009. The listing still carries a price, which makes this one of the era-defining indies still officially obtainable rather than archived.

It is a 2d painted-style platformer of the lightest technical class - the haswell igpu bar is far above its needs. Not-tested holds until a run confirms the install and the save structure.
