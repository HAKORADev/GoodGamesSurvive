ABOUT BEJEWELED 3

Bejeweled 3 is popcap's third and deepest match-3: the classic swap-and-match core sits inside eight modes - classic, zen, lightning, ice storm, gold rush, butterfly, poker and quest - each one a different reading of the same three-gem rule. The zen mode is the series' most famous detour: an endless, configurable corridor with breathing exercises and ambient tracks built in.

Popcap released it in december 2010, and the windows build on steam is the original popcap-era release, sold under the popcap label the studio carried before the ea fold-in. The listing still carries a price, which keeps it one of the match-3 shelf's live official doors rather than an archive rescue.

It is a 2010 casual 2d in the lowest requirements class - the haswell igpu bar is irrelevant to it, and the honest unknowns are the ones the status box carries: not-tested until a real run confirms the install and saves.
