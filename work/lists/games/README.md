# games database — work/lists/games/

files:

- `games.json` — the whole games database. one row per game. schema ggs.v1.
- `series.json` — series registry: every series with its members, ordered by
  part. series with modern upgrade paths (e.g. hitman -> World of Assassination)
  carry an `upgrades` block.
- `name-check/games-added.txt` — one canonical game name per line, sorted.
  the "is it already in the site" check. generated from games.json, also
  regenerated by CI (tools/lists_check.py).
- `expansions/` — dated expansion logs: what got expanded beyond the owner's
  lists, and where every fact came from.

## row classes (owner law)

| field | values | meaning |
|---|---|---|
| `list` | casual / non-casual | which owner list the game came from |
| `class` | normal / upgrade-of-normal | normal = its own game; upgrade-of-normal = a remaster/remake/re-release that upgrades a normal row |
| `series` | series key or null | part-of-series membership, drives the recommendation engine |
| `content_walls` | sex / gore | hard-wall content tags (NOT age ratings). gta being +18 is not a wall. |
| `big_size` | true/false | true only when the full version (highest tier, all DLC) needs more than 15 GB disk after repack download + unzip |
| `test_status` | tested / not-tested | tested = owner actually downloaded, played, pathed, modded. nothing else counts. |
| `confidence` | owner-listed / verified / verified-title | owner-listed = straight from owner lists. verified = facts checked with sources this round. verified-title = the title exists and is checked, the rest waits. |

## adding a game (short version)

1. search `name-check/games-added.txt` for the name. found = stop, it's in.
2. verify the facts (release date, developer, publisher, players, platform).
   sources into the row. unknown stays null.
3. tags: `sex` and `gore` are content walls, judge by what the game IS.
   `big_size`: measure the full tier, all DLC, installed size. more than
   15 GB = true, put the number in `big_size_gb`.
4. add the row to games.json, re-run tools/lists_check.py (or let CI do it).
   it regenerates the name-check file and prints the counts.
5. page gets built only after the row is verified.

full field reference in agents.md at the repo root.
